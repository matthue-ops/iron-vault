# FUT-003: Device or network restrictions for desk actions

Status: **DEFERRED — NOT APPROVED FOR IMPLEMENTATION**

Consider restricting sensitive staff desk operations, especially Manual Check-In, to approved devices or the gym's network. Motivation: an authorized staff account could otherwise record a manual entry remotely; attribution alone does not prevent this.

Before revisiting:

- Compare approved devices, gym-network restrictions and other practical options.
- Consider changing internet connections, shared devices, lost devices, remote owner access and recovery from lockouts.
- Decide which operations need restrictions and how exceptions would be authorized and audited.
- Inspect the actual deployed permission and offboarding controls first. A UI-only location or network check must not be presented as a server-enforced restriction.

No device, network or location restriction has been implemented for this proposal.
